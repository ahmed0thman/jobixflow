## 2. منطق الأعمال والقواعد الحاكمة
1. **الربط الجغرافي المسبق:**
   - تمثل الدول التقسيم الجغرافي الأساسي للنظام.
   - ترتبط كل شركة، مستخدم، ووظيفة بسجل دولة محدد.
2. **ربط بوابات الاتصال والمراسلة:**
   - **مزود الاتصال (Call Provider):** اسم أو معرف بوابة الاتصالات الهاتفية المعتمدة للعمليات في هذه الدولة.
   - **مزود الواتساب (Whatsapp Provider):** اسم أو معرف بوابة رسائل WhatsApp للإشعارات في هذه الدولة.
3. **عدادات تكامل الاستخدام:**
   - يحسب كل صف للدولة إجمالي الموارد المرتبطة بها:
     - `الشركات (Companies)`: إجمالي الشركات المسجلة تحت هذه الدولة.
     - `الوظائف (Jobs)`: إجمالي الوظائف المنشأة داخل نطاق هذه الدولة.
     - `المستخدمين (Users)`: إجمالي المستخدمين المنتمين لهذه الدولة.
   - يمنع النظام حذف أي دولة طالما ترتبط بها وظائف أو شركات نشطة لضمان سلامة البيانات.

---

## 3. تدفقات المستخدم والتفاعلات

### التدفق 1: إضافة دولة جديدة وربط المزودين
1. يضغط المدير على زر "Add Country" في صفحة `/platform/countries`.
2. تنبثق نافذة "Add New Country".
3. يدخل المدير البيانات:
   - `اسم الدولة (Country Name *)` (مثل: الإمارات العربية المتحدة، المملكة العربية السعودية، الولايات المتحدة).
   - `رمز الدولة (Country Code)` (مثل: `AE`, `SA`, `US`).
   - `مزود الاتصال (Call Provider)` (مثل: Twilio أو خادم SIP محلي).
   - `مزود الواتساب (Whatsapp Provider)` (مثل: Twilio WhatsApp أو MessageBird).
4. يضغط على "Create Country".
5. يقوم النظام بحفظ الدولة وإتاحتها فوراً في كافة القوائم المنسدلة لاختيار الدول عبر النظام بأكمله.

### التدفق 2: البحث وتصفية الدول
1. يكتب المدير في حقل البحث "Search by name".
2. يتم تصفية قائمة الدول تلقائياً أثناء الكتابة.

## 4. حالات الاستخدام والحالات الحدية (Edge Cases)

| الحالة | السيناريو | السلوك المتوقع |
|---|---|---|
| **حذف دولة مستخدمة** | محاولة حذف دولة لديها `Companies > 0` أو `Jobs > 0` | يتم رفض الحذف مع إظهار رسالة تفيد بوجود ارتباطات نشطة. |
| **عدم تحديد مزود الخدمة** | إنشاء دولة دون تحديد مزود الاتصال أو الواتساب | يتم إنشاء الدولة بنجاح، وتعتمد ميزات الاتصال على البوابة الافتراضية للمنصة. |

---

## 5. الاعتماديات ومخطط البيانات

### نموذج الكيان (`App\Models\Country`):
- `id`: المعرف الرقمي الأساسي
- `name`: اسم الدولة (نص إلزامي)
- `code`: رمز الدولة (ISO-2)
- `call_provider`: مزود الاتصال (اختياري)
- `whatsapp_provider`: مزود الواتساب (اختياري)
- العلاقات: `hasMany(Company::class)`, `hasMany(Job::class)`, `hasMany(User::class)`
