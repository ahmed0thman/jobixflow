# مدير المنصة: دليل العملاء (Customers Directory)

## 1. بيانات الصفحة
- **المسار (Route):** `/platform/customers`
- **صلاحية الدور:** `platform_admin`
- **عنوان الصفحة:** `JobixFlow - customers`
- **لقطة الشاشة:** [قائمة عملاء المنصة](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/platform-customers-list.png)

---

## 2. منطق الأعمال والقواعد الحاكمة
1. **المستودع المركزي للعملاء:**
   - يجمع كافة العملاء النهائيين الذين طلبوا خدمات الأقفال عبر أي شركة أو مرسل في النظام.
2. **عناصر بيانات العميل:**
   - `اسم العميل (Customer Name)`: الاسم الكامل لجهة الاتصال الأساسية.
   - `البريد الإلكتروني (Email)`: البريد الإلكتروني (اختياري).
   - `رقم الهاتف (Phone)`: رقم الهاتف الفريد المعتمد للاتصال.
   - `العنوان (Address)`: عنوان الخدمة الأساسي أو آخر موقع مسجل.
   - `الوظائف (Jobs)`: عدد الوظائف الإجمالي المرتبطة بهذا العميل طوال فترة استخدامه.
3. **البحث الشامل:**
   - إمكانية البحث متعدد الحقول بالاسم أو جزء من العنوان أو رقم الهاتف.

---

## 3. تدفقات المستخدم والتفاعلات
1. ينتقل المدير إلى `/platform/customers`.
2. يستخدم شريط البحث للاستعلام عن سجلات العملاء أو التحقق من حجم الوظائف السابقة المرتبطة برقم هاتف معين.

---

## 4. الاعتماديات ومخطط البيانات

### نموذج الكيان (`App\Models\Customer`):
- `id`: المعرف الرقمي الأساسي
- `name`: اسم العميل (إلزامي)
- `phone`: رقم الهاتف (إلزامي ومفهرس)
- `email`: البريد الإلكتروني (اختياري)
- `address`: نص العنوان (اختياري)
- العلاقات: `hasMany(Job::class)`
