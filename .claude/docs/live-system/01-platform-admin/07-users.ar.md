## 2. منطق الأعمال والقواعد الحاكمة
1. **نطاق مستخدمي المنصة:**
   - تختص هذه الشاشة بإدارة الكادر الداخلي للمنصة (`platform_admin` و `platform_dispatcher`).
   - تتم إدارة موظفي الشركات (مديري الشركات، المرسلين، والفنيين) داخل الوحدات المخصصة لكل شركة.
2. **أدوار المستخدمين والصلاحيات:**
   - `مدير المنصة (Platform Admin)`: وصول إداري كامل للشركات، التقارير المالية، سجلات التدقيق، والإعدادات.
   - `مرسل المنصة (Platform Dispatcher)`: وصول مقتصر على استقبال الطلبات، إنشاء الوظائف، وكتالوج الخدمات.
3. **قواعد التحقق عند الإنشاء:**
   - `اسم المستخدم (UserName *)` (فريد)، `البريد الإلكتروني (Email Address *)` (فريد وصحيح التنسيق)، `الدور (Role *)` (مدير منصة أو مرسل منصة)، `كلمة المرور وتأكيدها (Password & Confirm *)`، `الهاتف (Phone *)`، و`الدولة (Country)`.
4. **حماية المدير الأساسي:**
   - لا يمكن حذف أو تخفيض رتبة المدير الأساسي للنظام (`is_primary_admin = 1`).

---

## 3. تدفقات المستخدم والتفاعلات

### التدفق 1: إضافة موظف منصة جديد
1. يضغط المدير على "Create New" في صفحة `/platform/users`.
2. تنبثق النافذة بالحقول: الاسم الأول، اسم العائلة، اسم المستخدم، البريد الإلكتروني، اختيار الدور، الدولة، كلمة المرور، تأكيد كلمة المرور، ورقم الهاتف.
3. يدخل المدير البيانات ويضغط "Create User".
4. يتم تفعيل الحساب فوراً ليتمكن الموظف من تسجيل الدخول.

### التدفق 2: إعادة تعيين كلمة المرور أو تعديل البيانات
1. يضغط المدير على "Edit Password" أو "Edit" في صف المستخدم المحدد.
2. يتم حفظ التحديثات وإعادة تحميل الجدول تلقائياً.
