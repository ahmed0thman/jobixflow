## 2. منطق الأعمال والقواعد الحاكمة
1. **طابور الاستقبال والمقاييس التشغيلية:**
   - **إجمالي الوظائف (Total Jobs):** العدد الإجمالي للوظائف المرسلة عبر المنصة.
   - **غير المكتملة (UnCompleted):** عدد الوظائف النشطة قيد التنفيذ عبر الشركات الشريكة.
   - **المكتملة (Completed):** عدد الوظائف المنتهية بنجاح.
   - **الوظائف العاجلة (Urgent):** الوظائف المصنفة بأولوية عالية `High` والتي تتطلب تعييناً ومتابعة فورية.
2. **بث الوظائف الحديثة (Recent Jobs Stream):**
   - موجز مباشر يعرض اسم العميل، شارة الأولوية، الحالة الحالية، تصنيف العنصر (مثل: `Vehicle • 123 • Mr. Celestino Green`)، السعر التقديري، وتاريخ الإنشاء.
   - زر مباشر "New Job" للانتقال السريع لإنشاء وظيفة جديدة واستقبال العملاء.

---

## 3. تدفقات المستخدم والتفاعلات
1. يسجل المرسل دخوله إلى `/platform.dispatcher`.
2. يراجع عدادات الوظائف العاجلة (`Urgent`).
3. يراقب بث الوظائف الحديثة ويبدأ عملية استقبال العملاء الجدد بالضغط على "New Job".

---

## 4. الاعتماديات ومخطط البيانات
- `App\Models\Job`: `WHERE priority = 'high'`, `WHERE status NOT IN ('completed', 'cancelled')`
- بث مباشر للبيانات مدعوم بتحديثات WebSockets / Polling
