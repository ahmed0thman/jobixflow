# مدير الشركة: لوحة العمليات التشغيلية (Operations Dashboard)

## 1. بيانات الصفحة
- **المسار (Route):** `/companies.admin`
- **صلاحية الدور:** `company_admin`
- **عنوان الصفحة:** `JobixFlow - dashboard`
- **لقطة الشاشة:** [لوحة تحكم مدير الشركة](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/company-admin-dashboard.png)

---

## 2. منطق الأعمال والقواعد الحاكمة
1. **تنبيهات الوظائف العاجلة:**
   - شريط تنبيه بارز يوضح الوظائف العاجلة التي تتطلب تعييناً فورياً (مثل: `8 urgent jobs need immediate assignment`).
2. **بطاقات مؤشرات أداء الشركة (KPIs):**
   - **الوظائف النشطة (Active Jobs):** الوظائف الحالية الجاري تنفيذها بواسطة فنيي الشركة.
   - **الوظائف الجديدة (New Jobs):** الوظائف الواردة في انتظار إسنادها لفني.
   - **المكتملة اليوم (Completed Today):** الوظائف المنجزة بالكامل خلال اليوم الحالي.
   - **الفنيين المتاحين (Available Technicians):** نسبة الفنيين الجاهزين والمتصلين مقارنة بإجمالي فنيي الشركة (مثل: `8 of 11 total`).
3. **رسم بياني لاتجاه الإيرادات (Revenue Trend):**
   - يوضح مسار إيرادات الشركة الأسبوعية (من الجمعة إلى الخميس).
4. **توزيع أنواع الوظائف (Job Types Distribution):**
   - تصنيف تفاعلي لحجم الوظائف حسب نوع الأصل (مركبة `vehicle` مقابل باب `door`).
5. **شريط الوظائف الحديثة (Recent Jobs):**
   - يعرض أحدث بطاقات الوظائف مع اسم العميل، تصنيف العنصر، الفني المسند إليه، الأولوية، والحالة التشغيلية الحالية.

---

## 3. تدفقات المستخدم والتفاعلات
1. يسجل مدير الشركة دخوله إلى `/companies.admin`.
2. يفحص شريط التنبيه العاجل وتوافر الفنيين الميدانيين.
3. يحلل اتجاهات الإيرادات وتطور الوظائف الحديثة لفنيي الشركة.

---

## 4. الاعتماديات ومخطط البيانات
- `App\Models\Company`: سياق الشركة المحمل بناءً على `company_id` الخاص بالمستخدم المسجل.
- `App\Models\Job`: `WHERE company_id = {auth->company_id}`.
- `App\Models\User`: الفنيين المنتمين للشركة الحالية فقط.
