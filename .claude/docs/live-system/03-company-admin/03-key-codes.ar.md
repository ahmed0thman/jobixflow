# مدير الشركة: مستودع وتدقيق تكاليف أكواد المفاتيح (Key Codes Repository)

## 1. بيانات الصفحة
- **المسار (Route):** `/companies.admin/key_codes`
- **صلاحية الدور:** `company_admin`
- **عنوان الصفحة:** `JobixFlow - key Codes`
- **لقطة الشاشة:** [مستودع أكواد المفاتيح](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/company-admin-key-codes.png)

---

## 2. منطق الأعمال والقواعد الحاكمة
1. **المستودع التاريخي لأكواد المفاتيح:**
   - سجل دائم ومؤرشف لكافة أكواد قص وبرمجة المفاتيح المشتراة.
2. **أعمدة التدقيق المالي والتشغيلي:**
   - `الكود (Code)`: قيمة كود المفتاح الأبجدي الرقمي.
   - `التكلفة (Cost)`: تكلفة الشراء المالية التي تكبدتها الشركة.
   - `تم الحصول عليه بواسطة (User Obtained)`: الموظف أو الفني الذي سجل الكود.
   - `وظيفة المستخدم (User Job)`: دور المستخدم (`Technician`, `Company Admin`).
   - `الحالة (Status)`: صالح `Valid` (تم القص بنجاح) أو غير صالح `Invalid` (كود خاطئ من المزود).
   - `تاريخ الحصول عليه (Obtained Date)`: الطابع الزمني الدقيق للاستلام.
   - `الملاحظات (Notes)`: ملاحظات إضافية.

---

## 3. تدفقات المستخدم والتفاعلات
1. يفتح مدير الشركة `/companies.admin/key_codes`.
2. يبحث في الأكواد السابقة بقيمة الكود أو التكلفة أو اسم الفني.
3. يقوم بالتصفية حسب الحالة (`Valid` أو `Invalid`) لتدقيق جودة المزودين ومتابعة النفقات.

---

## 4. الاعتماديات ومخطط البيانات
- `App\Models\KeyCode`: `id`, `code_value`, `cost`, `obtained_by_user_id`, `status`, `notes`, `created_at`
