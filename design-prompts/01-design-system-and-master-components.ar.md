# مطالبة Stitch — الدفعة 01: نظام التصميم والمكونات الرئيسية الموحدة

## السياق والدور
أنت تقوم بتوليد نظام التصميم الأساسي ومكتبة المكونات الرئيسية الموحدة لمنصة **JobixFlow**—المنصة التشغيلية لإدارة أعمال فنيي الأقفال وتعدد الشركات.

## رموز ومتغيرات نظام التصميم (`R02-1`)
- **الألوان الأساسية:** `#3B82F6` (أزرق أساسي)، `#2563EB` (أزرق تفاعلي)، `#1D4ED8` (أزرق للتركيز).
- **الخلفيات والأسطح:** خلفية الصفحة `#F8FAFC` (Slate 50)، البطاقات `#FFFFFF`، القائمة الجانبية `#FFFFFF` بإطار `#E2E8F0`.
- **تدرج النصوص:** أساسي `#0F172A`، ثانوي/متوسط `#64748B`، خافت `#94A3B8`.
- **الشارات الدلالية:**
  - النجاح / مكتمل: النص `#16A34A`، الخلفية `#DCFCE7` (أخضر).
  - التحذير / معلق: النص `#D97706`، الخلفية `#FEF3C7` (كهرماني).
  - الخطر / عاجل / نزاع: النص `#DC2626`، الخلفية `#FEE2E2` (أحمر).
  - المعلومات / معين: النص `#2563EB`، الخلفية `#DBEAFE` (أزرق).
  - عتاد / مفتاح مادي: النص `#9333EA`، الخلفية `#F3E8FF` (بنفسجي).
- **الهندسة والانحناءات:** انحناء البطاقات `12px`، النوافذ `16px`، حقول الإدخال `8px`، الشارات `9999px`. إطار خفيف `1px solid #E2E8F0`.

## المكونات الرئيسية للتوليد (`R02-2`)

### 1. جدول البيانات الرئيسي الموحد `DataTable`
- **الأعمدة:** مربع اختيار، نص، شارة حالة، شارة أولوية، شارة مصدر (`منصة` مقابل `شركة`)، مبالغ مالية (موجهة مع رمز العملة `$`)، التاريخ والوقت، صورة واسم المستخدم، هاتف مقنع (`COM-001`)، مجموعة الإجراءات.
- **الميزات:** مؤشرات ترتيب، كثافة مريحة (`48px`) ومضغوطة (`36px`)، ترويسة مثبتة، تذييل ترقيم الصفحات (`10`، `25`، `50`) وإجمالي السجلات.
- **الحالات:** صفوف تحميل بهيكل عظمي Skeleton، رسالة لا توجد نتائج مع زر مسح الفلاتر.

### 2. شريط الفلترة الرئيسي الموحد `Filter`
- **العناصر:** صندوق بحث بأيقونة، قوائم منسدلة لكل عمود، محدد نطاق زمني مسبق (`اليوم`، `هذا الأسبوع`، `الأسبوع الماضي`، `نطاق مخصص`)، أزرار فلترة سريعة بعدادات، شريط بطاقات الفلاتر النشطة مع زر مسح الكل.

### 3. مجموعة الإجراءات الرئيسية الموحدة `Actions`
- **المجموعة:** `محادثة`، `واتساب/رسالة نصية`، `اتصال`، `عرض`، `تعديل`، `أرشفة` (بديل الحذف المشروط بالمدة `AUD-002`)، وقائمة فائضة `...`.
- **حالة التعطيل مع ذكر السبب:** زر باهت مع تلميح توضيحي.

### 4. الحالات الخمس الإلزامية (`R02-3`)
- **فارغ (Empty):** رسم توضيحي + رسالة + زر الإجراء الرئيسي.
- **لا توجد نتائج (No Results):** أيقونة بحث + نص الاستعلام + زر "مسح الفلاتر".
- **جارٍ التحميل (Loading):** صفوف وبطاقات هيكل عظمي نابض.
- **خطأ (Error):** أيقونة تنبيه + وصف الخطأ + زر إعادة المحاولة.
- **محظور الصلاحية (Permission Denied):** أيقونة درع + شرح صريح لسبب الاستبعاد.
