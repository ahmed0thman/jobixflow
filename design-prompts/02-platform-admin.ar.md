# مطالبة Stitch — الدفعة 02: بوابة مدير المنصة (`/platform`)

## السياق والدور
قم بتوليد تحديثات واجهات المستخدم والشاشات المالية الجديدة لـ **بوابة مدير المنصة** في منصة JobixFlow. حافظ على هيكل القائمة الجانبية الحالية، ونمط البطاقات، واللون الأزرق الأساسي (`#3B82F6`).

## مراجع لقطات الشاشة والتحديثات المطلوبة

### 1. لوحة التحكم وبث الوظائف النشطة
- **لقطة الشاشة المرجعية:** [platform-admin-dashboard.png](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/platform-admin-dashboard.png)
- **المتطلبات:**
  - بطاقات المؤشرات: إجمالي الشركات، الشركات النشطة، إجمالي الوظائف، إجمالي الإيراد ($)، ومستخدمي المنصة مع مؤشرات التغير.
  - جدول الوظائف النشطة: استخدام `DataTable` الموحد مع شارة المصدر (`منصة` مقابل `شركة`)، شارة الحالة اللحظية، شارة الأولوية (`عاجلة`/`متوسطة`/`منخفضة`)، السعر التقديري، وفلتر التواريخ.

### 2. نافذة تعديل الشركة وبطاقة إعدادات البوابة
- **لقطات الشاشة المرجعية:** [platform-companies-list.png](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/platform-companies-list.png)، [platform-companies-edit-modal.png](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/platform-companies-edit-modal.png)، [platform-company-details.png](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/platform-company-details.png)
- **المتطلبات:**
  - في نافذة التعديل: الإبقاء على حقل `العمولة Commission %` الإلزامي مع نص توضيحي: *"النسبة المئوية التي تقتطعها المنصة من معاملات بوابة الدفع التابعة للمنصة لهذه الشركة (`Q-02`)."*
  - في تفاصيل الشركة: إضافة **بطاقة حالة تكوين بوابات الشركة**:
    - `بوابة الدفع`: "بوابة المنصة (افتراضي)" أو "بوابة الشركة الخاصة (Stripe/Square)".
    - `نظام اتصال Twilio المقنع`: "مفعل (خاص بالشركة)" أو "غير مفعل".
    - ملاحظة العزل: *"الشركات التي تمتلك بوابتها الخاصة ورقم Twilio المستقل يتم عزلها عن محفظة المنصة وسجل التدقيق المركزي وفق `FIN-W-002` و `AUD-001`."*

### 3. تفاصيل الوظيفة — المصروفات، التفصيل الحسابي وشارات الاسترداد/النزاع
- **لقطات الشاشة المرجعية:** [platform-job-details.png](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/platform-job-details.png)، [platform-job-chat.png](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/platform-job-chat.png)
- **المتطلبات:**
  - **بطاقة مصروفات الوظيفة (`FIN-W-013`, `Q-16`):** بطاقة مخصصة مع وصف البند، التكلفة ($)، وشارة **الجهة الدافعة**: `دفع بواسطة الفني` مقابل `دفع بواسطة الشركة`.
  - **التفصيل الحسابي المتسلسل للدفع (`R02-6`):** كتلة تفصيلية: `السعر الإجمالي Gross` ← ناقص `المصروفات` ← ناقص `رسوم البوابة` ← `تقسيم عمولة المنصة والشركة` ← ناقص `رسوم الإرسال` ← `صافي المستحق Net`.
  - **بند رسوم انتقال الفني (`Q-20`):** "رسوم الانتقال: $[المبلغ] — محصلة / مرفوضة / متنازل عنها".
  - **شارات مستقلة للاسترداد والنزاع (`FIN-F-003`):**
    - `مستردة (Refunded)`: شارة كهرمانية مع المبلغ والمسؤول والسبب النصي.
    - `نزاع بنكي (Disputed)`: شارة حمراء مع روابط لأربعة عناصر (الوظيفة، الفاتورة، الدفع، الفني) + عداد الأيام المتبقية.
  - **إنفاذ القراءة فقط في المحادثة (`ROL-004`):** صندوق كتابة معطل مع شارة `👁 Only Show`.

### 4. إعادة هيكلة التقارير (`Q-08`)
- **لقطة الشاشة المرجعية:** [platform-reports.png](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/platform-reports.png)
- **المتطلبات:**
  - التبويب 1: **الرسوم البيانية التلخيصية** (أداء الفنيين، مسار الوظائف والإيرادات، توزيع أنواع الخدمات، المؤشرات الرئيسية).
  - التبويب 2: **شبكة التقارير التفصيلية** (`DataTable` مع خيارات تواريخ مسبقة، وزر تصدير إلى CSV/Excel): تقرير الوظائف، دفتر المعاملات المالية، وجدول أداء الفنيين.

### 5. تطوير سجل التدقيق (`AUD-001`)
- **لقطة الشاشة المرجعية:** [platform-audit-log.png](file:///Users/ahmedhisham/Work/Deltana/jobixflow/.claude/docs/live-system/screenshots/platform-audit-log.png)
- **المتطلبات:** إضافة عمودي `الشركة` و `نوع المستخدم`، فلاتر لكل عمود، وشريط تنبيه علوي بشأن عزل بيانات الشركات ذات البوابات المستقلة.

### 6. 🆕 شاشة جديدة: محفظة المنصة (`/platform/wallet`)
- **المتطلبات:**
  - بطاقات ملخص الأرصدة الأمانية: الرصيد الأماني الحالي، مدفوعات العملاء لهذا الأسبوع، عمولة المنصة المحتجزة، رسوم البوابة، إجمالي الاستردادات، والنزاعات النشطة.
  - جدول تفصيل أرصدة الشركات الشريكة.
  - دفتر المعاملات العام (`DataTable`): رقم المعاملة، التاريخ والوقت، الشركة، رقم الوظيفة، النوع، المبلغ ($)، المستخدم، والملاحظات. كشف حساب للقراءة والتدقيق فقط (`FIN-S-003`).
